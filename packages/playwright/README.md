# @gut.run/playwright

**A Playwright page, as a gut task's moves.** `observe(page)` returns what a round returns: the
page as context, and every control on it as ops, nested along the page's landmarks, headings and
items. `secret()` wraps a password the model may type but never reads. Bring your own `playwright`.

See the [gut README](https://github.com/fishballapp/gut#the-browser) for the API and how it does.
