# @gut.run/inspector

**The page `gut run --inspect` serves.** Every round and turn of a gut run, live: what the model
read, the options it was offered and the one it chose. Step through a run, answer a question
yourself, ask the model again with a different number of options, or edit what it reads and copy
the edit back into your task.

`@gut.run/cli` depends on it, so you never install it yourself. It is the page's built files only.
See the [gut README](https://github.com/fishballapp/gut#inspecting-a-run) for how to use it.
